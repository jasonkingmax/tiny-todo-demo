# Tiny TODO

一个简单的命令行待办工具，用于演示开源项目发布和变现流程。

## 安装

```bash
pip install tiny-todo-jasonkingmax
```

## 使用

```bash
# 添加任务
tiny-todo add 学习 Python

# 查看所有任务
tiny-todo list

# 完成任务
tiny-todo done 1
```

## 功能

- ✓ 添加待办事项
- ✓ 查看任务列表
- ✓ 标记任务完成
- ✓ 数据持久化存储

## 变现路径

这个项目演示了从开源到变现的完整流程：

1. **开源发布** - 免费发布到 GitHub 和 PyPI
2. **积累用户** - 通过实用功能吸引用户
3. **接受赞助** - 开通 GitHub Sponsors
4. **付费定制** - 根据用户需求开发新功能
5. **提供服务** - 为企业用户提供技术支持
